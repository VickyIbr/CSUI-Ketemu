# PRD: Ketemu - Platform Marketplace Event Edukasi

## BAGIAN 1: Visi & Tujuan Produk

### Visi Produk
Ketemu menjadi platform terpadu pertama di Indonesia yang menghubungkan pencari event edukasi dengan penyedia event berkualitas, mengatasi fragmentasi informasi event yang tersebar di berbagai channel, sekaligus memberikan pengalaman discovery yang mudah, transaksi yang aman, komunitas yang saling berbagi pengalaman belajar, dan portfolio karir terverifikasi via personal site/blog.

### Tujuan Utama

1. **Sederhanakan pencarian event edukasi** - Pengguna menemukan event dari berbagai penyedia dalam satu tempat tanpa harus mencari di banyak sumber, dengan tingkat keberhasilan pencarian di atas 80% dalam 3 klik.

2. **Tingkatkan transparansi dan kepercayaan** - Ulasan dari peserta nyata dan profil mitra yang lengkap membantu pengguna membuat keputusan yang tepat, ditargetkan minimal 70% pengguna membaca ulasan sebelum mendaftar.

3. **Fasilitasi transaksi yang aman dan mudah** - Pemesanan dan pembayaran terintegrasi dalam platform dengan success rate transaksi di atas 95%, menghilangkan risiko transfer manual dan konfirmasi berbelit.

4. **Berdayakan mitra mengelola event secara mandiri** - Tools lengkap untuk mitra membuat, mengelola, dan memonitor event mereka, mengurangi beban operasional manual hingga 60%.

5. **Bangun ekosistem komunitas pembelajar** - Fitur review dan sharing pengalaman menciptakan social proof yang membantu calon peserta memilih event yang tepat, target minimal 40% pengguna aktif memberikan ulasan.

### Value Proposition

- **Untuk Pencari Event:** Platform all-in-one untuk event edukasi (course, workshop, seminar, kompetisi) di Jakarta dengan ulasan terpercaya, pembayaran aman, dan personal site otomatis yang menampilkan portfolio terverifikasi dari event yang diikuti.

- **Untuk Mitra Event:** Channel distribusi dengan audience relevan, sistem pembayaran otomatis, dan tools manajemen event yang terintegrasi untuk membangun kredibilitas melalui feedback peserta.

- **Untuk Pengunjung Profil:** Melihat kredibilitas karir seseorang melalui riwayat event/course terverifikasi Ketemu lengkap dengan detail pencapaian dan target yang jelas.

## BAGIAN 3: User Stories

### Modul 1: Discovery & Event
- Sebagai pencari event, saya ingin mencari event berdasarkan kategori (course, workshop, seminar, kompetisi), agar menemukan yang sesuai minat.
- Sebagai pencari event, saya ingin melihat detail event (penjelasan, target pencapaian, kurikulum), agar yakin sebelum mendaftar.
- Sebagai pencari event, saya ingin melihat ulasan peserta sebelumnya, agar tahu kredibilitas mitra/event tersebut.

### Modul 2: Transaksi & Pembayaran
- Sebagai pencari event, saya ingin memesan tiket langsung di platform, agar praktis tanpa form eksternal.
- Sebagai pencari event, saya ingin membayar via berbagai metode digital, agar transaksi cepat dan aman.
- Sebagai mitra, saya ingin menerima notifikasi pembayaran otomatis, agar tidak perlu cek mutasi manual.
- Sebagai platform, saya ingin memotong komisi 5% secara otomatis, agar operasional tetap berjalan.

### Modul 3: Personal Site & Social Media
- Sebagai pengguna, saya ingin memiliki halaman profil (blog/personal site) khusus karir, agar bisa pamer skill ke publik.
- Sebagai pengguna, saya ingin event/course yang saya ikuti di Ketemu otomatis muncul di profil dengan label "Terverifikasi", agar pengunjung percaya kredibilitas saya.
- Sebagai pengunjung profil, saya ingin melihat detail event yang pernah diikuti pemilik profil, agar paham kedalaman skill mereka.
- Sebagai pengguna, saya ingin menulis post/blog di personal site saya, agar bisa berbagi insight layaknya LinkedIn.

### Modul 4: Mitra Tools
- Sebagai mitra, saya ingin membuat listing event dengan detail lengkap, agar menarik minat calon peserta.
- Sebagai mitra, saya ingin memantau daftar peserta dan pendapatan real-time, agar manajemen event lebih rapi.
- Sebagai mitra, saya ingin mengelola profil lembaga saya, agar reputasi terbangun dari kumpulan ulasan event.

## BAGIAN 4: Functional Requirements

### Modul 1: Autentikasi & Profil Pengguna

**FR-01: Registrasi & Login Pengguna**
- **Input:** Email, password, nama lengkap, tipe akun (User / Mitra)
- **Proses:** Validasi format email, hash password, verifikasi email OTP/link
- **Output:** Akun aktif, JWT token untuk akses platform
- **Aturan Bisnis:** Password min 8 karakter, email harus unik per akun

**FR-02: Profil Personal & Social Site (LinkedIn-style)**
- **Input:** Bio, headline karir, keahlian, riwayat pendidikan, postingan blog/artikel
- **Proses:** Simpan data profil, generate URL unik personal site (`ketemu.id/@username`)
- **Output:** Halaman profil publik yang dapat diakses publik/pengunjung
- **Aturan Bisnis:** Username unik, postingan bebas dibuat oleh pengguna (text, image, link)

**FR-03: Portfolio Event Terverifikasi Otomatis**
- **Input:** Data kelulusan/kehadiran dari mitra event/course Ketemu
- **Proses:** Sistem otomatis menarik riwayat event yang diikuti via Ketemu dan menambahkan badge "Terverifikasi Ketemu"
- **Output:** Section "Sertifikasi & Event Terverifikasi" di profil pengguna
- **Aturan Bisnis:** Badge terverifikasi HANYA diberikan jika pendaftaran & pembayaran dilakukan melalui Ketemu dan dikonfirmasi selesai oleh mitra

### Modul 2: Discovery & Listing Event

**FR-04: Pencarian & Filter Event**
- **Input:** Keyword, lokasi (default: Jakarta), kategori (Course, Workshop, Seminar, Kompetisi), harga, tanggal
- **Proses:** Matching query ke database event aktif
- **Output:** Daftar event/course yang relevan dengan sorting (Termurah, Terpopuler, Terdekat)
- **Aturan Bisnis:** Hanya event dengan status `Active` dan kuota > 0 yang tampil di hasil pencarian

**FR-05: Detail Halaman Event/Course**
- **Input:** Event ID
- **Proses:** Query data event, profil mitra, target pencapaian/silabus, ulasan peserta
- **Output:** Halaman detail lengkap event + tombol "Daftar Sekarang"
- **Aturan Bisnis:** Menampilkan badge mitra, rating rata-rata, dan kuota tersisa secara real-time

### Modul 3: Transaksi & Pemesanan

**FR-06: Checkout & Pemesanan Event**
- **Input:** Jumlah tiket/slot, data peserta (nama, email, no HP)
- **Proses:** Create booking record, generate Order ID, hitung total harga (Harga Event + Biaya Layanan jika ada)
- **Output:** Halaman instruksi pembayaran dengan invoice ID
- **Aturan Bisnis:** Slot sementara di-hold selama 15 menit proses pembayaran

**FR-07: Payment Gateway & Potongan Komisi**
- **Input:** Metode pembayaran (VA, E-Wallet, QRIS) via Payment Gateway
- **Proses:** Verifikasi pembayaran otomatis callback. Sistem split settlement: 95% untuk Mitra, 5% komisi platform Ketemu
- **Output:** Status pembayaran `Paid`, e-ticket / akses course terbit, notifikasi email ke user & mitra
- **Aturan Bisnis:** Komisi 5% dihitung dari harga dasar tiket/event. Pemotongan dilakukan otomatis saat settlement

### Modul 4: Komunitas & Ulasan

**FR-08: Sistem Ulasan & Rating Event**
- **Input:** Rating (1-5 bintang), ulasan teks, foto (opsional)
- **Proses:** Validasi status kehadiran user pada event/course tersebut, simpan ulasan, perbarui akumulasi rating mitra & event
- **Output:** Ulasan tampil di halaman detail event dan profil mitra
- **Aturan Bisnis:** Hanya peserta yang terdaftar dan menghadiri event/course via Ketemu yang dapat memberikan ulasan (Verified Review)

### Modul 5: Mitra Dashboard (Tools Mitra)

**FR-09: Manajemen Listing Event/Course**
- **Input:** Judul, deskripsi, kategori (Course/Workshop/Seminar/Kompetisi), lokasi/link online, silabus/target pencapaian, harga, kuota, tanggal & waktu
- **Proses:** Validate input, simpan draft atau publish event
- **Output:** Event terpublikasi di marketplace Ketemu
- **Aturan Bisnis:** Mitra harus melengkapi profil & data rekening sebelum bisa publish event

**FR-10: Dashboard Analytics & Data Peserta**
- **Input:** Range tanggal / filter event
- **Proses:** Kalkulasi total pendaftar, total pendapatan (gross & net setelah komisi 5%), daftar ekspor data peserta (CSV/Excel)
- **Output:** Tampilan chart pendapatan, statistik pendaftaran, dan opsi download data peserta
- **Aturan Bisnis:** Data finansial menampilkan rincian komisi 5% secara transparan

## BAGIAN 5: Non-Functional Requirements

### Performa
- **Waktu Muat:** Halaman utama dan detail event dimuat < 1,5 detik pada jaringan 4G stabil.
- **Responsivitas API:** Response time untuk endpoint pencarian dan transaksi < 300ms.
- **Konkurensi:** Sistem mampu menangani setidaknya 2.000 user aktif secara bersamaan (concurrent users) tanpa degradasi performa yang signifikan.

### Keamanan
- **Data Sensitif:** Password di-hash menggunakan bcrypt dengan salt yang kuat.
- **Transportasi Data:** Penggunaan enkripsi TLS 1.3 (HTTPS) wajib untuk semua trafik data.
- **Transaksi:** Integrasi payment gateway harus mematuhi standar PCI-DSS untuk penanganan data pembayaran.
- **Otentikasi:** Penggunaan JWT dengan masa berlaku (expiry) 24 jam dan implementasi refresh token.
- **Rate Limiting:** Proteksi API terhadap brute force dan spam (terutama pada fitur login dan pemesanan).

### Skalabilitas & Ketersediaan
- **Database:** Struktur database siap untuk sharding/read-replicas untuk mendukung pertumbuhan data user dan event.
- **Availability:** Uptime target 99,9% (high availability).
- **Infrastruktur:** Menggunakan load balancer untuk distribusi traffic dan auto-scaling group jika dibutuhkan.

### Usability (Kemudahan Penggunaan)
- **Desain Responsif:** UI/UX dioptimalkan untuk perangkat mobile (Mobile-first design) dan desktop.
- **Aksesibilitas:** Mematuhi standar dasar aksesibilitas web (kontras teks, ukuran target klik, navigasi keyboard).
- **Bahasa:** Mendukung Bahasa Indonesia sebagai bahasa utama.

### Kepatuhan & Privasi
- **Data User:** Kepatuhan terhadap UU Perlindungan Data Pribadi (UU PDP) Indonesia; data user tidak dibagikan kepada pihak ketiga tanpa persetujuan.
- **Audit Log:** Pencatatan log sistem untuk setiap transaksi finansial penting guna audit trail.

## BAGIAN 6: Out of Scope & Dependensi

### Out of Scope (Ditunda ke Versi Selanjutnya)

- **Payment Gateway Integration** - Saat ini menggunakan manual verification via QRIS upload + admin verification. Integrasi payment gateway (Xendit, Midtrans, dll) ditunda ke V1.1.
- **Mobile App Native** - V1 fokus web-responsive. Mobile app native (iOS/Android) pertimbangkan setelah user base stabil.
- **Integrasi Kalender (Google Calendar, iCal)** - Fitur export event ke kalender personal penundaan ke V1.2.
- **Fitur Kolaborasi Mitra** - Multiple admin per mitra event ditunda ke fase berikutnya.
- **Sertifikasi Digital Blockchain** - Badge/sertifikat blockchain ditunda.

### Dependensi Teknis & Eksternal

**Infrastruktur:**
- Database relasional (PostgreSQL/MySQL) untuk user, event, booking, transaksi
- File storage (AWS S3, GCS, atau lokal) untuk upload gambar event, profil, bukti pembayaran QRIS
- Email service (SendGrid, AWS SES) untuk notifikasi transaksi dan user
- CDN untuk caching statis assets (opsional, bisa ditambah fase berikutnya)

**Payment & Finansial:**
- Payment Gateway (nanti): Xendit, Midtrans, atau Doku untuk payment processing V1.1
- Bank API untuk live account balance verification mitra
- Akuntansi: integrasi laporan keuangan untuk admin dashboard

**Eksternal:**
- Compliance: Konsultasi legal untuk UU PDP Indonesia dan persyaratan marketplace
- Registrasi legalitas: PT. Ketemu atau CV Ketemu untuk izin usaha

### Model Revenue & Komisi (Configurable)

**User Monetization:**
1. **Free with Ads + Sponsored Content** - Akses marketplace gratis, tampilkan iklan in-feed, logo/banner sponsor di halaman utama dan event listing
2. **Premium Subscription** - Rp 29-49K/bulan: bebas ads, featured course priority visibility, unlimited bookmark, priority support

**Mitra Monetization (Flexible & Configurable):**
1. **Komisi Per-Transaksi** - Default 5% per booking (dapat disesuaikan per mitra). Cocok untuk volume rendah, low commitment.
2. **Subscription Bulanan** - Rp 99-299K/bulan (tier: Starter/Pro/Enterprise). Event unlimited, komisi rendah (0-2%), kuota peserta terbatas per tier.
3. **Paket Premium Services (Add-on):**
   - Event Design & Copywriting - Rp 500K-2M per project
   - Marketing & Promotion (Social media, email campaign) - Rp 1M-5M per campaign
   - Vendor Management (Tempat, catering, equipment) - Konsultasi + coordinasi, fee per event
   - On-Site Verification & Support - Tim Ketemu datang untuk verifikasi peserta/tempat, Rp 500K-1M per event

**Revenue Mix (Target):**
- User subscription: 10-15% × Rp 40K = recurring revenue
- Ads & sponsored content: CPM Rp 5-15K per 1000 impressions
- Komisi per-transaksi: 5% × GMV (dari pay-per-event mitra)
- Mitra subscription: 20-30% × Rp 150K = recurring revenue mitra
- Premium services: 10-15% mitra × Rp 1-2M per tahun

**Konfigurasi Sistem:**
- Komisi rate dapat diubah per mitra atau global via admin dashboard (tidak hardcoded)
- Subscription pricing tier dapat di-adjust via backend config
- Feature gating (ads, featured placement, bookmark) dapat di-toggle per user tier
- Premium service packages dapat ditambah/dihapus tanpa development

### Asumsi Bisnis

- **Pengguna Target V1:** 1.000-5.000 user aktif dalam 6 bulan pertama, fokus Jakarta
- **Mitra Target V1:** 50-100 mitra aktif listing event
- **Conversion Rate:** 5-10% dari viewer menjadi pembeli tiket/pendaftar
- **User Subscription Adoption:** 10-15% dari total user dalam 6 bulan
- **Mitra Subscription Adoption:** 20-30% dari total mitra dalam tahun pertama
- **Payment Success Rate:** 95%+ untuk QRIS manual, meningkat menjadi 98%+ saat payment gateway live
