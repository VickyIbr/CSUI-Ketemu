# CSUI-KeTemu

Prototype platform event kampus dengan light theme putih + kuning + biru.

## Tech Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 3.4
- shadcn/ui (new-york style)
- Zustand (state management)
- React Router 7

## Design System

- Paper: #ffffff
- Ink: #14161a
- Highlighter: #ffd43b
- Ink Blue: #1d3fd1

## Features

- Event discovery & filtering
- Checkout with 5% commission
- QRIS payment
- E-ticket generation
- Personal site & blog
- Partner dashboard & analytics
- Account management

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
